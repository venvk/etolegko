# Замер скорости скачивания

10 последовательных GET-запросов к заданному адресу, каждый раз дожидается полного тела ответа.
Таблица с объёмом, временем и скоростью каждого запроса выводится в реальном времени, в конце печатаются среднее время запроса, общий объём и скорость.

Внешних зависимостей нет, нужен только Python 3.12+ со стандартной библиотекой.

## Запуск

```bash
python3 main.py https://etolegko.ru/img/covers/6_skolkovo.jpg
```

## Единицы измерения

- **Скорость: Mbit/s, мегабиты в секунду** (1 Mbit = 10^6 бит). В этих единицах указывают скорость интернета провайдеры и сервисы вроде Speedtest. В скобках та же скорость в MB/s (мегабайты в секунду).
- **Объём: MB** (1 MB = 10^6 байт), в скобках точное число байт.
- **Среднее время запроса: миллисекунды.**

Как считается:

- среднее время = суммарное время всех запросов / число запросов;
- скорость = суммарный объём / суммарное время запросов.

Время одного запроса включает отправку запроса, ожидание ответа, редиректы и чтение тела до последнего байта.

## Почему быстро

- **Полностью асинхронный, на `asyncio` из стандартной библиотеки.** Запросы идут последовательно, один за другим. HTTP/1.1 разбирается самим скриптом в `asyncio.BufferedProtocol`, это самый нижний уровень asyncio, без `requests`/`httpx`/`aiohttp`.
- **Одно keep-alive соединение на все запросы.** TCP- и TLS-рукопожатие проходит один раз, если сервер поддерживает keep-alive. Если сервер закрыл простаивающее соединение, скрипт переподключается и повторяет запрос.
- **Сокет пишет данные прямо в один заранее выделенный буфер на 256 KiB.** Тело ответа только подсчитывается: данные не копируются, не накапливаются в памяти и не создаются новые объекты `bytes` на каждый кусок, поэтому расход памяти не зависит от размера файла.
- **`Accept-Encoding: identity`.** Сервер не сжимает ответ, и скрипт считает реально переданные байты.
- Скрипт следует редиректам (до 5) и завершается с ошибкой на ответах не 2xx, чтобы не замерять страницу 404 вместо файла.

### Сравнение

10 запросов файла 200 MB (всего 2 GB) с локального сервера, macOS, Python 3.15, httpx 0.28.1, requests 2.34.2. Медиана 6 прогонов на каждый клиент. Localhost убирает сеть из уравнения, и остаются только накладные расходы самого клиента.

| Клиент | Время | Пиковая память (RSS) |
|---|---|---|
| **main.py** (`asyncio.BufferedProtocol`) | **0.39 s** | **30 MB** |
| `requests.Session` + `iter_content` | 0.44 s | 38 MB |
| `httpx.Client.stream` + `iter_bytes` | 0.81 s | 38 MB |
| `requests.get(url).content` | 1.05 s | 518 MB |
